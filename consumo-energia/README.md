# 🖩 Calculadora de consumo de energia elétrica inteligente
Esta calculadora, desenvolvida em Python, foi criada para realizar os cálculos de estimativa de quanto um aparelho utiliza, mensalmente, de energia elétrica.
A calculadora solicita dados de consumo, como a **potência do aparelho em watts (W)**, o **tempo médio de uso diário em horas (h)** e, se possível, o **valor fixo do kWh em Reais (R$)**.
Com esses dados, a calculadora retorna o **consumo médio do mês em kWh** e, se preenchido, o **valor do custo em Reais**.
