# 💻 Sistema de cálculo de descontos progressivos.
## 👨🏽‍💻 Autor: Kaio Henrique
ℹ️ Esse sistema foi criado em python, com objetivo de calcular descontos por meio do valor de compra dos usuários de uma loja online. Com objetivo de utilizar as condicionais if e else, o sistema aborda as condições de acordo com os valores totais das compras dos usuários.
