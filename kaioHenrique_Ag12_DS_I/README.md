## 📝 Sobre o Projeto
A **Página de Sites favoritos** é o primenti desenvolvimento em HTML, que serve para compreender a linguagem, sua estrutura e tags.

## ✨ Funcionalidades
- 📱 **Imagens:** Exibição de imagens por meio das tags <img> e <scr>.
- 🔗 **Direcionamento por link:** Redirecionamento ao site correspondente, por meio dos links das tags <a href>.

### Pré-requisitos para a execução o programa
- Ter um navegador que suporte rodar HTML 5.
